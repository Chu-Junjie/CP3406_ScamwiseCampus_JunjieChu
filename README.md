# ScamWise Campus

ScamWise Campus is an interactive Android education app designed to help university students recognise scam warning signs, practise safe verification decisions, and evaluate the accuracy of their confidence.

## Target Audience

University students aged approximately 18–25.

## Core Features

- Scenario-based scam awareness activities
- Risk assessment and warning-sign identification
- Safe-action decision practice
- Adaptive practice recommendations
- Confidence calibration feedback
- Learning progress and statistics
- Online URL verification
- Accessibility and privacy-focused settings

## Technology

- Kotlin
- Jetpack Compose
- Material Design 3
- MVVM
- Koin
- Navigation Compose
- Room
- Retrofit
- Kotlin Coroutines
- DataStore
